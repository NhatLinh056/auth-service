Service Integration Guide

How client microservices connect and authenticate with Auth Service.

AppAuth: Ready
1 Configure Environment (.env)

Store your AppID and AppToken in your client microservice configuration file.

AUTH_SERVICE_URL=http://localhost:3000 APP_ID=app_xxxxxxxxxxxxxxxxxxxxxxxx APP_TOKEN=apt_xxxxxxxxxxxxxxxxxxxxxxxx...
2 Attach Request Headers

Inject service credentials into HTTP request headers when calling Auth Service.

X-App-Id: app_xxxxxxxxxxxxxxxxxxxxxxxx X-App-Token: apt_xxxxxxxxxxxxxxxxxxxx... Content-Type: application/json
3 Service Handshake Verification

AppAuthGuard verifies credentials against PostgreSQL and returns 200 OK.

GET /auth/verify-service HTTP/1.1 200 OK { "valid": true, "status": "ACTIVE" }
