Cách Microservice Khác Kết Nối Tới Auth Service

Quy trình 3 bước đơn giản để bất kỳ microservice nào (như Demo Service, Billing,...) xác thực bảo mật qua AppID & AppToken.

Cơ Chế AppAuth: Sẵn Sàng
1. Microservice Client
Đọc AppID & AppToken từ .env
HTTP Request + Headers
X-App-Id / X-App-Token →
2. Auth Service (Port 3000)
AppAuthGuard đối soát DB PostgreSQL
Phản Hồi Xác Thực
200 OK (ACTIVE) →
3. Truy Cập Thành Công
Xử lý nghiệp vụ & dữ liệu
1
Lấy AppID & AppToken Cấu hình .env

Tạo ứng dụng trong tab "Ứng Dụng", sao chép AppID và AppToken dán vào file cấu hình của microservice.

.env (Microservice) 
AUTH_SERVICE_URL=http://localhost:3000
AUTH_SERVICE_APP_ID=app_22c57454b00eb44a...
AUTH_SERVICE_APP_TOKEN=apt_789f2a41d0bc8...
2
Gửi Kèm 2 Header HTTP X-App-Id & X-App-Token

Khi microservice gọi bất kỳ API nào tới Auth Service, gắn kèm 2 header chứng thực vào HTTP Request.

HTTP Headers 
X-App-Id: app_22c57454b00eb44a...
X-App-Token: apt_789f2a41d0bc8...
Content-Type: application/json
3
Auth Service Tự Động Xác Thực AppAuthGuard

AppAuthGuard đối soát DB PostgreSQL. Nếu token hợp lệ và trạng thái BẬT (ACTIVE), yêu cầu được phê duyệt ngay.

Response (200 OK) 
HTTP/1.1 200 OK
{
  "valid": true,
  "appId": "app_22c57454...",
  "status": "ACTIVE"
}
